----------------------------------------
DESCRIPCIÓN
----------------------------------------

Este proyecto consiste en una página web educativa sobre la inclusión.
El objetivo es generar conciencia sobre la importancia de la igualdad,
el respeto y la accesibilidad para todas las personas.

La web incluye contenido informativo, un video explicativo y una sección
interactiva con códigos QR que permiten ampliar la información.

----------------------------------------
FUNCIONALIDADES
----------------------------------------

- Video introductorio sobre inclusión
- Sección informativa clara y accesible
- Códigos QR interactivos (clic para ampliar)
- Diseño moderno y responsive
- Modal para visualizar QR en grande
- Navegación fluida entre secciones
- Banner visual al final
- Créditos del autor
